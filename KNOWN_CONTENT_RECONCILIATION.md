# Known Content Reconciliation Items

RC3 deliberately does not silently rewrite recovered Alpha content when it conflicts with later repository metadata.

## License wording

The currently published Alpha `contributing` page states that the repository is licensed under the **MIT License**, while the reconstructed/expanded repository metadata and `LICENSE.md` identify **PDDL 1.0**. RC3 preserves the published contribution text and the repository license metadata so the discrepancy is visible and can be resolved deliberately before a final 1.0.0 release.

This is a content-governance issue, not a preservation failure.
