### Glossary

<div class="table-wrap">

| Term              | Definition                                                                                                 |
|-------------------|------------------------------------------------------------------------------------------------------------|
| Crosswalk         | Mapping table that connects identifiers from ServiceNow to identifiers in ArcGIS Indoors.                  |
| Dead-letter queue | Queue of events that failed after defined retry attempts and require human review.                         |
| Feature layer     | ArcGIS layer that stores and exposes features and attributes for querying, editing, display, and analysis. |
| Idempotency       | Design property that allows duplicate event delivery without duplicate side effects.                       |
| Operational layer | Derived ArcGIS layer showing current or recent ITSM/ITAM activity.                                         |
| Webhook           | HTTP callback used to notify another system that an event occurred.                                        |
